# Anchor — App 问题清单

- 日期：2026-11-09
- 范围：**仅 App 本身的问题**；展示/答辩相关问题不在本清单
- 依据：对当前打包版（`AnchorDemo-0.2.0`）与源码的逐项检查，以及本机运行数据库的实际状态

1. App 语音输入链路不通：真机识别不出任何字；本机 DB 里 0 条音频回合，录音→上传→识别在 App 端就是断的。
2. 服务端 ASR 只有 Windows SAPI：按停顿截断、无标点、无置信度、无语言识别。
3. 没有接入任何真实 ASR 供应商：`asr_http` 只是未实测的适配器，无供应商、无 key、无实测。
4. 语音输出只有 SAPI 机械音：停顿语调恐怖谷，无神经音色、无 SSML。
5. 没有服务端 TTS：只有客户端起 PowerShell 子进程念字；Android 的 flutter_tts 路径也未验证。
6. 语音全链路 ASR→LLM→TTS 串行：无流式、无首字延迟指标。
7. 无 barge-in、无回声消除、无播放队列管理；Stop 只是杀进程。
8. 主动联系只在 App 前台且 Home 可见时轮询：App 一关就永远不会再联系。
9. 打包版没有调度器/worker：DB `jobs=0`，服务端不会自己产生“下一次问候”。
10. 周报没有任何生成入口：DB `digests=0`，Settings 只有“已有周报”的预览/审批/编辑。
11. 家人端永远是空/信息不足，因为周报根本不会生成。
12. 家人端全链路（邀请→接受→老人批准→生成→审批→查看→电话）没有一次端到端跑通。
13. 家人通知不存在：只有 DB 里的 notification 行，没有推送/邮件/系统通知。
14. 会话会卡死：`proactive` 会话长期停在 `active`，关 App 不结束，后续被 409/`active_session` 挡住。
15. Android 打电话未测试：桌面端 `tel:` 无拨号器；Android 真机的拨号链路也没有验证。
16. 可观测几乎为零：只有 `/api/v1/health` 和一个 append-only 的 `backend.log`。
17. 没有指标、链路追踪、request id 关联、provider 延迟/错误率、成本统计、告警。
18. 没有审计/运营可见性：同意变更、撤销、删除、通话发起虽然写库，但 App 里看不到。
19. 关键路径没有 E2E：347 后端 + 159 Flutter 都是单测/组件测试，语音、主动联系、周报、家人端全靠 fake。
20. 没有 hands-free 唤醒：只有按键说话，“语音优先”目前只是 push-to-talk。
21. 打包版是 Debug、未签名：44MB、启动慢、可能被 SmartScreen/杀软拦截。
22. 演示数据会自我阻塞：已有 check-in attempt 或 active session 就不弹主动问候，且没有重置保护。

## 2026-11-09 晚 · v0.3.0 的状态变更

今晚只动 TTS 与语音输入两件事，下面只覆盖这两件，其余条目未验证、按原样生效。

- **4（SAPI 机械音）、5（没有服务端 TTS）→ 已修，并在本机 v0.3.0 上实测。** 后端新增
  `POST /api/v1/tts`（edge-tts，默认 `zh-CN-XiaoxiaoNeural`，语速 −12%），App 每句话改为向后端取
  mp3、用一次性的 PowerShell `MediaPlayer` 子进程播放，SAPI 只做失败兜底。实测：一条 12 字回复 →
  15,840 字节 mp3，播放 4.27 s，临时文件随后删除；冻结构建的 exe 内实测 30 字 → 27 KB / 6.64 s。
  代价写清楚：**离线不可用**（会退回 SAPI），**每句 3–7 s 延迟**，合成文本会发往微软 Edge 服务。
- **1（语音输入链路）、2（SAPI 识别质量）、3（无真实 ASR 供应商）→ 仍未解决。** 链路和
  OpenAI 兼容的 `HttpASR` 都在，但要靠 `Settings → AI 接入` 填 `base_url / key / model` 才切过去，
  **目前没有任何 ASR key，一次真实识别都没跑过**。今晚的实测顺带确认：麦克风能录（3 s / 527 KB），
  但 SAPI 认不出真实中文，所以"0 条音频回合"是识别失败，不是麦克风坏。
- **19（测试数量）→ 363 后端 + 177 Flutter**，`scripts/verify.ps1 -SkipBuild` 绿；但全绿仍然只是
  单测，不等于产品可用。

其余 16 条没有任何变化。
