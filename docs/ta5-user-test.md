# Anchor — formative usability session

Status: protocol and blank forms. No participants have been tested by this coding session. Follow course requirements for participant recruitment and consent. Do not collect identifiable health stories for a classroom demonstration.

## Before the session

Use the exact rebuilt app, a known network, synthetic report data, and a consenting adult participant. Explain: “We are testing the app, not you. You can skip any task or stop at any time.” Explain cloud processing before using speech. Obtain permission before recording; notes without names are usually sufficient for usability observations. A small set of 3–5 older adults plus caregiver observations is a practical starting point, not a rubric rule or a representative sample.

Use participant codes such as P01. Note device, build, language, text scale, and whether the person is familiar with the device. Allow breaks and stop on request.

## Tasks to read aloud

1. “You would like a short conversation. Please start one.”
2. “Imagine the app did not understand you. Please try again or use another way.”
3. “You want it to stop listening or talking now. Please stop it.”
4. “You want to see what a family member could learn about your week. Please find the draft.”
5. “You are happy with the draft. Please share it.” Use synthetic data and a test family account only.
6. “You no longer want your mood information shared. Please change that.”
7. “Please remove this saved fact.” Identify one synthetic fact, not a participant’s private information.
8. “You want to contact this consenting family member.” Stop before dialing if the number is a placeholder. For device testing, use only a number the team is authorized to call.

Do not point to controls before the first attempt. Log prompts and help separately. An abandoned task is an observation, not a failure of the participant.

## Short interview

- What did you think the app was doing while you waited?
- What could your family see, and what stayed private?
- How would you change sharing without your family’s help?
- Did the flower reward feel encouraging, childish, like a score, or something else?
- What would make you choose to use this again?

Ask openly before offering examples. Separate participant quotations from the team’s interpretation.

## Report results honestly

Report numerator and denominator for each task, with aided attempts separate. Example format only: “[x] of [n] participants completed [task] without help.” Replace all brackets with real data or omit the claim. Do not pool senior and caregiver tasks into one percentage.

For each high-priority issue record: observed behavior; affected task; proposed change; why; retest result. Until retested, mark the result “pending.” No invented quotes, no claim of clinical benefit, and no claim that the small sample represents all older adults.
