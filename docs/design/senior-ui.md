# 老人端 UI 重设计 · 设计说明（2026-11-10）

范围：**Windows 老人终端**的登录页、首页、聊天页；子女/配置端不改排版。
目标设备：13–15 寸笔记本触摸屏，握持距离 40–60 cm，用户 70–85 岁。
依据：WCAG AAA 对比度目标、65+ 触控目标 48–56 px、正文 ≥18 px、行高 ≥1.6 的通用建议，
以及本机实测（正文 26 px、触控 56 px 已在用，问题不在字号而在版面与信息架构）。

## 一、设计判断（为什么不是"换配色"）

1. **一屏只有一个主角。** 聊天和活动已合流，首页不再需要三个并列入口；首页的主角是"说话"这件事，
   它应该是屏幕上一个可触摸的实体，而不是一排等权按钮。
2. **动作永不随内容滚走。** 老人的手不会去找按钮：说话键与停止键固定在底部，字幕在其上滚动。
3. **留白是结构，不是装饰。** 去掉设置后空出的空间由"问候 + 一朵花 + 说话盘"占据，
   而不是再塞一排卡片；卡片只留给真正需要边界的东西（活动卡、告警）。
4. **字幕是对话，不是消息列表。** 去掉头像、气泡、间距堆叠：一句一行、行距紧凑，靠底对齐。

## 二、设计 token

| 类别 | 名称 | 值 | 用途 |
|---|---|---|---|
| 底色 | paper | `#F2EFE4` | 全屏底（暖石色，避开"奶油+赭石"的模板感） |
| 抬升 | paperRaised | `#FAF8F0` | 卡片/面板 |
| 墨色 | ink | `#17211B` | 正文（对 paper ≈ 13.8:1） |
| 次级墨 | inkSoft | `#3D4A41` | 标签、辅助句（≈ 7.9:1） |
| 线 | line | `#CFC9B6` | 发丝分隔线、卡片描边 |
| 主动作 | jade | `#1F5C46` | 说话盘、主按钮（≈ 6.0:1 对 paper） |
| 主动作深 | jadeDeep | `#16432F` | 按下态 |
| 次动作 | ochre | `#9C6B1F` | 玩一玩、小花（≈ 4.6:1） |
| 听音信号 | teal | `#0E7A76` | 收音时的呼吸环，仅此处使用 |
| 停止 | brick | `#8C2F23` | 停止条（≈ 7.4:1），**只出现停止条一处** |
| 反馈 | correct / wrong / open | `#E3EFE6` / `#F8ECD8` / `#F4EFE5` | 保持现状 |

字号（不改小）：正文 26 / 标题 30–34 / 区块 36 / 首页问候 44；行高正文 1.35（更紧凑），标题 1.2。
圆角：面板 20，按钮 16，说话盘圆形。间距刻度：8 / 12 / 16 / 24 / 32 / 48。
动效：按下缩到 0.97（120 ms）；收音呼吸环 2.4 s 循环，`MediaQuery.disableAnimations` 时静止；
字幕入场 fade + 上移 8 px（180 ms），每次只说一次话。

## 四、边界

- 子女/配置端（手机 setup）**有自己的一套排版**（2026-11-11 补做，见第五节），只共用
  token 与字号下限，不复用老人的大动作按钮。
- 停止：按下后只出现"已经停下来了"的提示与恢复入口，停止条仍然贴在底部。
- 播放/收音状态用文字 + 图标表达，颜色永远不是唯一通道。

## 五、手机端（家人 / 设置）2026-11-11

同一套纸墨配色，但形状相反：老人端是"一个大目标"，手机端是"一页要读完的面板"。
老人在电脑前站着按一下，家人是在手机上用拇指从上往下读。所以手机端有自己的零件
（`mobile/lib/widgets/hub.dart`），不复用 `BigActionButton`。

| 零件 | 用途 | 规格 |
|---|---|---|
| `HubHeader` | 页头：玉色竖条 + 22 px 小标签 + 34 px 标题 | 小标签 `jade`，标题 `ink` |
| `HubReadout` | 一行读数"标签：值" | `paperRaised` + `line` 边，23 px |
| `HubSectionLabel` | 分组小标题 + 一条发丝线 | 22 px `inkSoft`，字距 1 |
| `HubRow` | 可打开的一行：46 px 图标块 + 26 px 标签 + chevron | ≥56 px，圆角 16 |
| `HubPanel` | 一块文字/表单（比行更安静） | 圆角 20，`paperRaised` |
| `HubNote` | 说明块：淡玉/淡赭 | 圆角 20，2 px 边 |
| `HubPrimaryButton` | **一屏最多一个**主动作 | jade 实底，76 px |

改到的屏幕：手机首页（设置与联络）、家人这边、本周简报、提议问候时间、输入邀请码；
`StatusBanner` 也从界面自己编的灰黄/粉红挪回 `ochre` / `brick` 家族。

规则（和老人端一样硬）：
1. 一屏只有一个实底主按钮，其余都是行或说明块。
2. 字号下限 22 px，正文 24–26 px，标题 28–34 px；1.6× 文字不许溢出。
3. 颜色不是唯一通道：连接状态、选项选中、简报状态都另有文字或对勾。
4. 没做的东西就写"还没做"，例如审计记录仍只在电脑端（首页记录块照旧这么说）。

**还没改的**：AI 接入页（`ai_providers_screen.dart`，624 行）与设置与设备页
（`settings_screen.dart`，932 行）仍是上一版的分节卡片排版；它们用的是旧 token
（配色已跟随），但排版没有按第五节重做。
