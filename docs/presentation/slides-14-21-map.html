① 14–15

怎么跑

机制：先给外形，再进内部

14

Windows 主机 + Android 客户端

45s
  • 一台笔记本跑全部：Flutter 界面 + FastAPI + SQLite
  • 手机只是客户端：只拉报告、不开麦
  • 一条局域网：HTTP/TCP 8077，发现用 UDP 8078
  • 代价：主机必须开着；定时周报要 worker，手动不用
15

语音、字幕与兜底

60s
  • 四段：识别 → 对话 → 语音输出 → 恢复
  • 打字可绕过麦克风，不依赖录音
  • 输出：DeepSeek 主 / Edge 备 / 设备语音
  • 失败是设计过的：字幕不断、Stop 一直可用、一键重试

② 16–17

证明了什么

后端冒烟检查了什么

60s
  • 8 组检查：真实本地 socket + 临时库 + 合成数据

两个平台都通过

45s

  • 方法：本地 HTTP、合成记录、测试适配器

③ 18–19

需要什么、多少钱

运营：可行性是组织问题

18

课堂试点需要什么

40s
  • 一台可达的主机：库与服务同机，网络要预演
  • 失败预案：合成语音 + 打字 + 走查脚本

19

每月 API 成本（示意）

35s
  • 10 轮/天 × 30 天
  • 每轮 1,000 输入 / 100 输出 token，50 字语音
  • 合计 ≈ US$1.48 / 户·月（聊天 ~0.13 + 语音 ~1.35）
  • 不含电费、网络、存储、支持、重试；不是账单
